## Description

This is a blog application built with PHP, using OOP principles and an MVC architecture. It supports user authentication and full post management, and was built to deepen my understanding of PHP and server-side web development. The application allows users to register, log in, create, edit, and delete blog posts. It also implements security measures such as password hashing and input validation to protect against common vulnerabilities.
