## Description

A frontend todo list application rebuilt from scratch using React and TypeScript. The app interacts with a provided RESTful API to manage todos, supporting creation, completion, deletion. The project focuses on understanding React core concepts such as components, state management, and hooks, as well as clean code organisation and reusability. The application is deployed on GitHub Pages.
