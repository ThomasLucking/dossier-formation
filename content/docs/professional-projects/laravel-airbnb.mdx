## Description

An Airbnb-inspired rental application built with Laravel 12. Users can list apartments with several images, browse and filter properties (by ownership or booking history, sorted by price or number of rooms) and book them for a date range. The booking system detects date conflicts and calculates the price automatically. The home page shows the 3 most-booked destinations. Users can edit their profile, and admins can manage users from an admin panel. Policy-based authorization makes sure users can only manage their own data.
