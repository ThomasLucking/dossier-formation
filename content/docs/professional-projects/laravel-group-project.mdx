## Description

A Laravel 13 web application that tracks projects, their leaders and members through several stages (proposition, evaluation, in progress, archive). Projects follow a state machine, and resource contributions are capped at 200%. Scheduled Artisan commands send reminder and warning emails to the leaders of stale projects, and old projects are archived automatically. Roles and permissions restrict what each user can do. Code style is enforced with Laravel Pint through a Git pre-commit hook (CaptainHook), and a CI workflow runs Pint, PHPStan and the tests on every pull request.
