## Description

A full-stack ticketing application where users create IT support tickets and the support team handles them. It includes authentication, ticket creation with images, real-time comments over WebSockets, and an admin dashboard with search and pagination where support staff assign tickets and change their status. Assignment and status changes are recorded in the ticket's comment thread. The project started on SQLite and was migrated to PostgreSQL with Drizzle ORM. Work was planned with user stories and GitHub issues.
