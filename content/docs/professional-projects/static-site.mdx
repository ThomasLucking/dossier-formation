## Description

A static website built exclusively with HTML and CSS, faithfully reproducing a provided design mockup at 1920×1080px resolution. The project focuses on mastering modern CSS layout techniques such as Flexbox and Grid, semantic HTML, and clean code organisation. No JavaScript was used. The codebase was managed with Git using conventional commits, with one commit minimum per task linked to the corresponding GitHub issue.
