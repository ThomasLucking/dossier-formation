## Description

A Laravel application that imports a Markdown corpus into PostgreSQL, splits each document into text fragments and stores an embedding for each fragment with pgvector. It offers three modes: full-text word search, meaning search by vector similarity with a configurable threshold, and generated answers from a local Ollama model that cite their source documents. Workshop members can also browse documents and manage project records through forms with server-side validation. The search modes were benchmarked on a fixed set of test questions, and two embedding models were compared (`nomic-embed-text` vs `qwen3-embedding:4b`). The final step, migrating the search to Laravel Scout, was not completed.
